# 2026-07-31

## Category Groups — implemented

Added category groups to the budgeting system:

- **Data model**: new `productivity/groups.csv` (Recurring, Food, Travel, Leisure, Investments). `categories.csv` now has a `group` column mapping every category to exactly one group. Unassigned categories fall under "Other" (never lost).
- **Vite config** (`/api/categories` + new `/api/groups`): CRUD for both; group rename propagates to categories; group delete moves its categories to "Other"; `/api/categories/reorder` swaps within the same group (up/down).
- **api.ts**: `getCategories()` now returns `CategoryRow[]` (`{name, group}`); added `getGroups/addGroup/updateGroup/deleteGroup` and `reorderCategory`.
- **budgetLoader.ts**: `computeEnvelopes` takes `categories: {name,group}[]` + `groups: string[]`; each envelope carries `group`; `EnvelopeState.groups` is the ordered list filtered to groups that have envelopes. Rollover caps negatives at 0.
- **EnvelopeGrid**: collapsible group header rows with rolled-up Assigned/Spent/Available (red/green available), expand/collapse-all toggle in the header, search auto-expands + shows only matching groups, PAYOFF (credit card) row pinned at the bottom outside groups.
- **CategoryManager**: categories clustered under group headers; per-category group dropdown; ↑/↓ reorder within group; rename/delete group (delete moves cats to Other); add-category can pick a group; new "Add Group" section.
- **package.json prebuild** now copies `groups.csv` to `public/productivity/`.
- Fixed rollover flow in `ExpensePage.handleRolloverConfirm` to map category rows → names.
